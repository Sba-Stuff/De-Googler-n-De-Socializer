A powerful browser extension that helps you break free from social media addiction and big-tech platforms by blocking distracting websites and suggesting ethical, privacy-focused alternatives.


## 🌟 Features

- **Smart Blocking**: Automatically blocks social media and big-tech websites
- **Alternative Suggestions**: Shows relevant privacy-respecting alternatives for blocked sites
- **Customizable Block List**: Edit `blocked_sites.txt` to add or remove domains
- **Lightweight**: Uses Chrome's declarativeNetRequest API for efficient blocking
- **Privacy First**: No tracking, no data collection, completely open source
- **Instant Redirect**: Blocks pages before they load, saving bandwidth and time

## 🎯 Blocked Categories

- **Social Media**: Facebook, Instagram, Twitter/X, LinkedIn, TikTok, Reddit, Pinterest, Snapchat
- **Google Services**: Google Search, YouTube, Gmail, Google Drive, Google Maps, Google News
- **Messaging**: WhatsApp, Messenger, WeChat, Telegram

## 📦 Installation

### From Source (Developer Mode)

1. **Download the extension files**
   ```bash
   git clone https://github.com/Sba-Stuff/de-googler-n-de-socializer.git
   cd de-googler-n-de-socializer
   ```
2. **Turn Browser Developer Mode On In Extenions**
Turn Your browser developer mode on in extension settings

3. **Load Unpacked Extension**
Click on Load Unpacked Extensiona and select that de-googler-n-de-socializer folder you created earlier.

4. **Enjoy Freedom **

Note: The extension was built for Google Chrome, Feel Free to Modify it as per your convenience.
